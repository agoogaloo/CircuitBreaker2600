# Circuit Breaker 2600

## About
This is a demake of [Circuit Breaker](https://github.com/vicente-david/Circuit-Breaker) (A previous game I helped make) for the atari 2600. It has been adapted to fit within the hardware contraints of the atari 2600 (4 KB ROM and 128 bytes of RAM)

## Running
The latest ROM can be downlaoded from Releases and played with your favourite atari 2600 emulator ([Stella](https://stella-emu.github.io/downloads.html) is a good one)
You can also play it in your browser on 8bitworkshop [Here](http://8bitworkshop.com/redir.html?platform=vcs&githubURL=https%3A%2F%2Fgithub.com%2Fagoogaloo%2Fatari2600-game&file=vsync.a).
